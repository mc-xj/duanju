# 《破晓太原》介绍PPT · 重绘情感版

使用 PPT Master 6.9.0，在已确认的30页电影叙事结构上重新绘制20张专用配图，并增加动作、表情、光影与情绪解读。交付中文16:9可编辑PPTX、PDF及逐页讲解稿。

## 本版更新

- 新绘封面、12场主画面、右腕红布细节、4位独立团角色肖像及陈峰的现代/战时双身份肖像。
- 构图围绕文字区域设计：封面、告别和结尾预留安静画面；宽幅分场图把关键面部与动作置于安全区域。
- 增加回望同伴、手掌包扎、抓住衣袖、递水壶、抚平红布等有剧情依据的细节，突出惶惑、牵挂、失去与铭记。
- 文字与关系图形仍为原生可编辑对象；图片独立嵌入并可替换，逐页备注同步更新。
- 片头、片尾、分集卡和记忆闪回样图仍展示仓库既有素材，便于介绍原制作资产。

## 文件

- `破晓太原_介绍PPT_重绘情感版.pptx`：30页正式演示文稿。
- `破晓太原_介绍PPT_重绘情感版.pdf`：由SVG源版式生成的静态预览，保留设计换行。
- `配图/`：20张独立新绘图片，保留生成时实际像素尺寸，未放大冒充更高分辨率。
- `逐页讲解稿.md`：与PPT备注相对应的讲解文字。
- `逐页素材索引.json`：每页可见文字及图片路径。
- `绘图提示词与依据.json`：每张新图的用途、提示词、角色/布局参考及实际尺寸。
- `SVG源文件/`：30页源文件，图片采用仓库相对路径，完整下载仓库后可一起查看。
- `设计说明.md`、`执行参数.md`、`排版检查报告.json`：设计与核验记录。

## 依据与完成度

叙事与人物关系依照文学润色版、融合分镜和独立分场文档；原镜数与时间码保留。新绘图为PPT介绍插画，不覆盖原104张分镜，不增加新的剧情镜号。原脚本592秒正片加8秒片尾为600秒，新片头及分集卡需另行分配时长。

本片1945年太原攻城属架空；真实太原解放于1949年4月24日。静帧资产齐备不等于视频成片完成。新增的情绪描述是对人物与画面的解读，不作为新增人物对白。

源仓库版本：`17d50ee`。制作日期：2026-11-09。旧版分别保留。

最终SVG质量闸门无阻断错误；剩余提示主要为图片体积，导出使用显示尺寸优化。PPT与PDF均核对30页，含逐页备注。
