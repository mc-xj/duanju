## 资料口径

叙事依据 GitHub `mc-xj/duanju` 的 `rename/lilong-longcheng` 分支（5982a50），采用文学润色版、融合分镜、独立分场与制作时间码。原片12场104镜，正片592秒加片尾8秒为600秒。104张剧情关键帧、8张人物参考、14张字幕卡和20张既有PPT插画按各自用途区分，不等同于最终视频成片。

新片名采用“破晓龙城”，人物采用“李龙”；现实史实对照保留太原1949年4月24日解放，1945年的攻城为架空叙事。图片使用仓库原有分镜和PPT专用插画；只优化本PPT内嵌图片体积，原素材未改动。

字体使用 Noto Sans CJK SC 与 Noto Serif CJK SC。在其他电脑编辑时，建议安装相应字体以保持排版。静态预览用于快速核对视觉效果。

本次不覆盖旧版介绍PPT，不修改剧本与分镜原文件。
