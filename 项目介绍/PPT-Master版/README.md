# 《破晓龙城》项目介绍 · PPT Master版

本版依据用户确认的“电影叙事”方向，使用 PPT Master 6.9.0 的 SVG → 原生 DrawingML 流程重新制作。共30页、16:9，文字与关系图形可在PowerPoint中继续编辑，配有逐页讲解备注。

## 文件

- `破晓龙城_项目介绍_PPT-Master.pptx`：正式演示文稿。
- `破晓龙城_项目介绍_PPT-Master.pdf`：静态预览。
- `逐页讲解稿.md`：30页讲解文字，亦已写入PPT备注。
- `逐页素材索引.json`：逐页文字与图片原始仓库路径。
- `设计说明.md`、`执行参数.md`：设计方案和跨页参数记录。
- `排版检查报告.json`：30页最终SVG检查结果，0项阻断错误。

## 内容与依据

介绍作品定位、双时间线、陈峰成长、人物群像、12场剧情、红布信物、视觉和空间呼应、字幕卡、制作流程、声音与完成度。叙事依据文学润色版、双稿融合修订版及逐场分镜，时间依据JSON清单，画面全部选自当前仓库。

源仓库版本：`26a6d38`。制作日期：2026-11-09。

## 核验

PPTX和PDF各30页；PPT包含30页备注与339个原生可编辑文字段。原生导出质量闸门通过；剩余9项提示仅针对源图片相对显示尺寸偏大，已采用按显示尺寸优化的导出选项。图片本身为嵌入的位图，文字与关系图形为可编辑对象。

本片1945年攻城属于架空虚构，真实太原解放于1949年4月24日。现有104张分镜为静帧资产，不等于最终视频完成。原脚本592秒正片加8秒片尾，共600秒；新增片头及分集标题卡需在后续剪辑中重新分配时长。
