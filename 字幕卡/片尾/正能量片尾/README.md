1. 铭记先辈：记住他们，也珍惜今天。
2. 致敬守护者：平凡的肩膀，也能托起希望。
3. 不负青春：把先辈的嘱托，写进今天的努力。
4. 珍爱和平：山河无恙，岁月安宁。

图片02中的扶老场景、图片03的图书馆和图片04的和平街景属于片尾象征性延展，不是原剧本里新增的王根生生还情节。人物、旧物与晨光用于呼应短剧主题。

可选其中一张使用，或按01至04依次展示。原有片尾字幕卡保留。原脚本592秒正片与8秒片尾合计600秒；如新增展示时长，需重新分配片尾时间或调整总片长。
