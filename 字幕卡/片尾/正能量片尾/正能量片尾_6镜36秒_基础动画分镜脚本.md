# 正能量片尾基础动画分镜脚本

依据：本目录6张现有片尾图片，以新版“军装勋章退伍老兵”画面作为《致敬守护者》首帧。适用于图生视频及剪辑软件制作动态片尾。

## 一、统一执行标准

- 共6镜，每镜6秒，合计36秒。24 fps，每镜144帧，全段864帧。
- 输出1916×821，沿用原图实际比例，不拉伸为其他宽银幕比例。
- 按原图生成连续单镜头。每镜只保留一个主要动作，辅以轻微环境变化；不增加情节或人物。
- 原图为首帧，锁定面孔、服装、人数、站位、光向、道具和文字位置。老人穿军装、佩戴勋章的身份必须保留。
- 人物动作以呼吸、眼神、小幅手部动作和身体重心变化为限；不走出原位置，不转身，不大幅抬手，不强求同步口型。
- 全画幅保持稳定。若运镜，采用剪辑软件缓慢推近至102%，不要同时进行横移、环绕或拉焦。文字单独固定，不随底图缩放。
- 文字必须保持静止、准确、清晰。优先用原图文字区域作静态遮罩或独立文字图层；不要依赖视频模型重绘书法、标语及报纸文字。运动区域避开文字，保持边缘自然。
- 各镜按下表时间码依次硬切，不用重叠转场缩短总时长。第一镜淡入、末镜淡出均包含在各自6秒内。需要柔化接点时，另行设计镜内亮度过渡，不挤占相邻镜头。
- 无新增旁白。配乐采用舒缓、庄重、逐渐温暖的无歌词音乐；先克制，再舒展，最后收静。具体音乐素材另行选定。
- 以下是动画制作脚本，不代表已经生成动态视频。片尾图属于主题创作，并非历史影像；现代老兵画面不暗示剧中王根生生还。

## 三、逐镜执行

### E01｜山河不屈

**素材**：`片尾_05_山河不屈.png`。

**固定文字**：山河不屈 / 以血肉之躯，守护家国。

**表达**：以短暂、克制的战斗片段引出今天生活的来之不易。

**景别与机位**：宽幅中远景，保持原图敌我两侧阵地关系，基本固定机位。

**6秒节拍**：

- 0—2秒：从黑场用0.5秒淡入，原有烟尘缓慢向同一方向漂移；战士维持掩护和瞄准姿态。
- 2—4秒：原图中段持枪战士完成一次轻微射击动作，短促枪口火光、极小肩部后坐，枪口仍指向远处敌方阵地。其余人物保持原位。
- 4—6秒：淡烟延续，战士恢复稳定瞄准，右上方晨光保持温暖；不新增爆炸、倒地或冲锋动作。

**基础运镜**：固定机位优先，可在后期整体缓推1%，文字层不动。

**声音**：低音弦乐起；远枪声与一声短促步枪声低音量出现，不盖过配乐。

**图生视频提示词**：

> 以所给图片为首帧，生成6秒连续写实电影镜头。严格保留原图灰布军装战士与远处土黄军服日军的分区站位，双方处于不同阵地，枪口方向不变。仅让薄烟和尘埃缓慢漂移；原图中段正在瞄准的战士轻微扣动扳机一次，枪口短暂微光、肩部极轻后坐后回稳。其他人物只做微弱呼吸，不改变原有位置与姿势。光照稳定，固定摄影机，无剪切。左侧全部中文文字完全静止。保持原图人物、步枪、沙袋和城墙结构，不增加人物或新事件。

**简化替代**：若枪口或持枪手变形，取消射击动画，只保留烟尘、呼吸与后期慢推，枪声留在画外。

### E02｜胜利的曙光

**素材**：`片尾_06_胜利的曙光.png`。

**固定文字**：胜利的曙光 / 山河重光，万众同庆。报纸“抗战胜利”保持原样。

**表达**：从紧张转为释放，以街头军民欢庆象征1945年抗战胜利。

**景别与机位**：宽幅群像，固定原图构图。

**6秒节拍**：

- 0—2秒：群众保持原有表情和姿势，少量纸屑缓慢飘落，树叶轻动。
- 2—4秒：举报纸青年微微仰头、笑容自然加深；手臂只轻微晃动，报纸位置、四角及大字稳定，不再次举高。旁人轻微呼吸与喜悦表情变化。
- 4—6秒：纸屑继续缓落，青年保持微笑；前景老人眼眶湿润、微微点头，不新增拥抱或击鼓大动作。

**基础运镜**：固定机位，后期缓推至101.5%即可。

**声音**：配乐渐暖，叠加很轻的欢呼与远锣鼓，不添加可辨认的新增台词。

**图生视频提示词**：

> 以所给图片为首帧，制作6秒连续电影片尾。1945年中国老城群众庆祝抗战胜利。保留所有人物站位、衣服、城楼、红绸及报纸，不新增人群。主体青年维持举报姿势，仅轻微仰头并自然微笑；周围群众只有轻微呼吸、微笑与小幅点头。少量现有纸屑慢慢飘落，树叶轻摆，暖金阳光稳定。相机固定，无转场。左上标题和副标题保持完全静止清晰；报纸「抗战胜利」不得变形、跳字或重绘。不要新增挥臂、跳跃、拥抱、旗帜或镜头旋转。

**简化替代**：若人脸或报纸不稳定，冻结人物和报纸，仅制作纸屑、树叶与后期慢推。

### E03｜致敬守护者

**素材**：`片尾_02_致敬守护者.png`，使用已重绘的军装勋章老兵版本。

**固定文字**：致敬守护者 / 平凡的肩膀，也能托起希望。

**表达**：让“守护”在现代日常中得到回应，表现对退伍老兵的尊重。

**景别与机位**：双人全身景，保留左文右人、桥边红布铁锹的结构。

**6秒节拍**：

- 0—2秒：两人保持搀扶关系，轻微呼吸；水面细小涟漪、树叶轻摆。
- 2—4秒：老人朝陪伴者轻微点头、笑意加深；陪伴者温和回应，搀扶的手和搭肩手位置不变。
- 4—6秒：两人重心轻微前移后停稳，不做完整迈步；军装胸前勋章仅随呼吸小幅晃动，铁锹上的红布末端轻轻摆动。

**基础运镜**：固定机位；不要绕行或侧移，以免改变面孔和左右关系。

**声音**：温暖弦乐与轻风、水声，不强加脚步声或对白。

**图生视频提示词**：

> 以所给军装勋章退伍老兵图片为首帧，生成6秒写实片尾镜头。保持左右人物身份和原有搀扶姿态：白发老人身穿橄榄绿色军装，胸前原有勋章数量、形状、位置不变，中年男子一手扶上臂、一手搭肩。只做轻微呼吸、老人一次小幅点头和自然微笑，陪伴者眼神温和回应；双脚保持原位，不迈步。军装织物和勋章随呼吸极小幅自然运动。水面轻微涟漪，树叶与铁锹木柄上的红布末端轻摆，铁锹本体不动。固定摄影机，暖金光照稳定。左侧两行中文文字完全静止，不变字。无新增勋章、无变脸、无手脚重叠、无道具漂移。

**简化替代**：若搀扶手部或勋章不稳定，冻结双人及勋章，只动水面、树叶和红布末端。

### E04｜不负青春

**素材**：`片尾_03_不负青春.png`。

**固定文字**：不负青春 / 把先辈的嘱托，写进今天的努力。

**表达**：把“好好念书”的嘱托转为当下具体的行动。

**景别与机位**：青年侧面中近景，维持书、笔记和红布的原始位置。

**6秒节拍**：

- 0—2秒：陈峰低头阅读，轻微呼吸与一次自然眨眼，右手保持握笔。
- 2—4秒：笔尖在原笔记区域缓慢移动一小段，左手继续扶书；不要求生成任何可读字。
- 4—6秒：笔尖短暂停住，目光略微移向书页，红布与旧书保持静止；背景人物不走动，只作极轻微虚化变化。

**基础运镜**：后期缓推至102%，保持人物面孔和左侧文案完整。

**声音**：轻微纸笔摩擦声，舒缓配乐延续，不翻页。

**图生视频提示词**：

> 以所给图片为首帧，制作6秒连续写实电影镜头。青年陈峰穿灰色连帽卫衣、戴黑框眼镜，面孔、发型和坐姿保持原样。仅有轻微呼吸、一次自然眨眼，右手握笔在当前笔记区域缓慢写一小段，随后停笔；左手始终扶在原书页位置，不翻页。手指数量和握笔结构正确。旧书旁红布完全静止，不重新绑到手腕。背景虚化人群不走位，窗外树叶小幅轻动，阳光柔和稳定。固定机位，左上两行文字清晰静止。不要抬头转身、不要新增可读笔记、不要书本变形或手部增生。

**简化替代**：若写字导致手指异常，冻结双手，保留眨眼、呼吸、窗外树影与后期缓推。

### E05｜珍爱和平

**素材**：`片尾_04_珍爱和平.png`。

**固定文字**：珍爱和平 / 山河无恙，岁月安宁。

**表达**：用日常生活回应前面的奋斗与守护。

**景别与机位**：老城街道全景，家庭背影与古城门保持原位。

**6秒节拍**：

- 0—2秒：树叶轻摆，雨后路面有稳定柔光；早餐摊蒸汽缓缓上升。
- 2—4秒：牵手的一家人只做轻微身体起伏、衣摆小幅摆动，不生成完整行走周期；牵手关系不变。
- 4—6秒：蒸汽延续，远处行人和骑车老人位置保持稳定，晨光轻微变暖后稳定。

**基础运镜**：固定机位，或后期缓推1%；不追踪行人，不横移。

**声音**：很轻的城市晨间环境声与鸟鸣，配乐舒展；不添加车辆喇叭。

**图生视频提示词**：

> 以所给图片为首帧，生成6秒和平生活电影片尾，原图古城门、街道、一家人、早餐摊和自行车位置全部保留。只让树叶轻微摇动、早餐蒸汽缓缓升起，牵手家庭轻微呼吸和身体起伏、衣摆轻摆，双脚不换位、不生成迈步，牵手结构稳定。远处人群与自行车不移动、不增减。阳光轻微变暖，路面反光稳定。固定镜头，无剪切、无横移。左上标题副标题全部固定清晰，不发生重绘或漂移。自然温暖、动作非常克制。

**简化替代**：人物全部静止，只制作树叶、蒸汽与轻微光影，就能形成稳定的动态片尾。

### E06｜铭记先辈

**素材**：`片尾_01_铭记先辈.png`。

**固定文字**：铭记先辈 / 记住他们，也珍惜今天。

**表达**：最终回到旧书与红布，让情绪安静落下。

**景别与机位**：桌面静物近景，固定镜头，不让道具移动。

**6秒节拍**：

- 0—2秒：晨光中只有细微浮尘缓慢移动，窗外树影轻晃。
- 2—4秒：窗纱缓慢轻动，花瓣极轻微颤动；红布、旧书与钢笔保持原位。
- 4—5秒：所有动态逐渐平稳，文字继续完整停留，保留阅读与回味。
- 5—6秒：在剪辑软件中将整个画面连同文字、配乐统一淡出至黑，6秒结束时完全黑场，不额外追加时长。

**基础运镜**：固定镜头，或后期缓推1%；不翻书，不掀红布。

**声音**：环境声逐步减弱，配乐尾音在5—6秒内淡出。

**图生视频提示词**：

> 以所给旧书、红布、白花和钢笔图片为首帧，生成6秒连续电影静物镜头。保持所有物件的形状、材质、位置和数量。仅使晨光中极少量细尘缓慢飘动，窗纱轻摆，窗外树叶投下轻微移动的光影，花瓣只有非常细小的自然颤动。旧书不翻页，红布不移动，钢笔不滚动，不出现人手。固定摄影机，曝光稳定。左侧「铭记先辈」和「记住他们，也珍惜今天」全程准确清晰静止。模型只生成稳定画面，最终淡黑由后期完成。

**简化替代**：只做静态图的缓推与淡黑，配少量光尘叠加即可。

## 四、通用负向要求

变脸、肢体增生、手指错误、衣服变款、胸章漂移、勋章增减、人物走位、人与道具融合、枪械弯曲、枪口乱指、重复人物、报纸变形、字幕跳字、书法重绘、红布消失、时代物件混入、光线闪烁、剧烈抖动、快速拉焦、镜头旋转、突然剪切、强烈爆炸、流血与额外剧情。

## 五、最稳妥的制作方式

1. 每张原图制作6秒图生视频，优先选择固定机位与低运动强度；保留原始图片备份。
2. 将中文标题、副标题及报纸大字所在区域固定为静态层。必要时改为剪辑软件分层动画，避免模型重绘文字。
3. 无法稳定生成的人物动作直接取消，保留环境动画和后期1%—2%缓推即可。不要为“动起来”强行加入复杂行为。
4. 片段按E01至E06排列，各自占满6秒。添加原定淡入淡出与低音量环境声，不改变镜长。
5. 导出前核对：6段×6秒＝36秒；24 fps下共864帧；文字无错字、人物无变形、军服与勋章稳定、红布道具保留。

## 六、与原片的时长关系

原剧本为592秒正片＋8秒原片尾＝600秒。本36秒动态片尾若接在原片尾之后，全片为636秒，即10分36秒；若替换原8秒片尾，全片为628秒，即10分28秒。替换时应在其他位置保留必要的架空与史实说明。

若全片必须严格保持10分钟，不能直接追加本片尾，应从正片或其他片段中重新分配时长。本脚本只定义新增6镜各6秒，不擅自删减原剧情。
